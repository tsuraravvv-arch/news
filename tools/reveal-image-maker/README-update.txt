Reveal Image Maker v0.18.1
更新日時: 2026-07-29 21:40 JST

目的
- 投稿できた1086×1448と、投稿できなかった3072×4096の間を同一条件で切り分ける。

主な変更
- 1086×1448 / 1440×1920 / 1728×2304 / 2304×3072 / 3072×4096 の5つの保存ボタンを追加。
- 同じ元画像・同じ選択マスク・同じPNG-8処理を使い、解像度だけを変更。
- 出力は3:4固定。元画像は変形せず中央トリミングでキャンバス全面へ配置。
- 透明率と完全透明の外周幅を保存後に表示。
- 1px対角チェッカー、2値透明、透明インデックス0、255色パレット、sRGBチャンクを維持。

推奨テスト順
1. 1086×1448
2. 1440×1920
3. 1728×2304
4. 2304×3072
5. 3072×4096

各ファイルを個別にPC版Xへ投稿し、最初に失敗する解像度を確認してください。
