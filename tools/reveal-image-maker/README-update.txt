Reveal Image Maker v0.17.8 update

変更概要
- 長辺4096px出力を維持したまま、隠し領域のパターンを 64x64 非周期（Trial B）から 32x32 準非周期（Trial C）へ変更
- 狙いは、Bayer4の規則模様を弱めつつ、64x64非周期で出やすかった砂状ノイズを少し抑えること
- 保存は引き続き PNG-8（本命）と RGBA PNG（診断用）の比較保存に対応

今回の狙い
1. X投稿時のクリック後で、周期的な粒模様が目立ちにくいか
2. 64x64非周期よりも、背景や肌のざらつきが少し穏やかになるか
3. 投稿可否やプレビュー整合性が維持できるか

使い方
1. 通常どおり画像を読み込み、見せる範囲を塗る
2. プレビューで白TLと黒背景の両方を確認
3. まず PNG-8 を保存して X へ投稿確認
4. 必要なら RGBA PNG も保存し、挙動比較に使う

補足
- 出力は長辺4096px相当（縦横比維持）
- 透明構造は単一透明色＋2値透明パターン
- プレビューは白背景/黒背景へ合成後、長辺900px相当へ縮小して近似表示
