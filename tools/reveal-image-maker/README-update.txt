Reveal Image Maker v0.18.0 reference-checker trial

今回の目的
- 添付された2つの綺麗な参考PNGの実ファイル構造を再現する
- 複雑なBayer・準非周期・Blue-noise方式をやめ、1px単位の単純な対角チェッカーへ戻す

参考PNGから確認できた共通構造
- PNG-8（パレット画像）
- アルファは0 / 255の2値のみ
- 見せる範囲は完全不透明
- 隠し範囲は2×2対角チェッカーで約50%透明
- 高解像度のまま保存し、Xやブラウザの縮小平均化で滑らかに見せる

今回の実装
- 出力サイズは元画像のまま維持
- 隠し領域は (x + y) が偶数の画素だけ不透明にする1px市松
- 隠し領域のRGBは元画像色をそのまま使用
- 明度ブーストは1.00固定
- PNG-8のみ保存
- ファイル名を短い英数字に固定

確認したい点
1. Xクリック後の格子・モアレ・線が、過去の32x32/64x64方式より減るか
2. 高解像度画像で、参考例のように滑らかな暗いカラー画像へ近づくか
3. 白タイムラインで隠し領域が十分に消えるか
4. 元画像の解像度による差がどの程度あるか
