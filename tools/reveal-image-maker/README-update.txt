Reveal Image Maker 更新メモ（v0.6.0 rgb preserved update）

今回の調整
- 隠し領域のRGBを「白に近い狭い明度帯」へ圧縮する方式へ変更
- 黒い線や暗い衣装だけが強く残りすぎないよう、先に彩度と色差を軽く圧縮
- 完全な無彩色化は避け、元画像の色味を少しだけ残すよう調整
- クリック後プレビュー（黒背景）は、白背景より少し見えやすくなるよう非破壊プレビュー係数を更新
- 右上のバージョン表示は継続し、更新日時を v0.6.0 に更新

主な変更値
- hiddenAlpha: base 96 / strong 118
- toneMin: 232 -> 228（boostでやや低下）
- toneMax: 248 -> 244（boostでやや低下）
- contrast: 11 -> 16
- hueKeep: 0.08 -> 0.12
- revealHiddenAlphaScale: 1.12

意図
- 白背景では、隠した部分が「ほぼ白」に寄って見えにくい
- 黒背景では、同じ画素が半透明の明るい色として残り、輪郭や表情をうっすら認識しやすい
- boost を上げたときは、透明度を極端に変えずに階調差を少し広げる
