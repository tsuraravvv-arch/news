Reveal Image Maker v0.17.9 update

変更概要
- X表示安定モードを追加し、出力を 3:4 固定（3072×4096）キャンバスへ再配置
- 被写体を少し小さめ（subjectScale 0.86）に中央寄せ配置し、クリック後の見かけサイズを安定させる方向を試験
- ファイル名を短縮（rv179a / p8 / rgba）し、投稿エラーの切り分けをしやすく変更
- 隠し領域のパターンは 32x32 準非周期（Trial C系）を維持

今回の狙い
1. Xのクリック後で被写体が大きくなりすぎず、粒感が相対的に目立ちにくくなるか
2. ブラウザの表示倍率差に対して、見え方が少し安定するか
3. 短いファイル名にすることで、投稿時エラー要因の一部を切り分けられるか

使い方
1. 通常どおり画像を読み込み、見せる範囲を塗る
2. プレビューで白TLと黒背景の両方を確認
3. まず PNG-8 を保存して X へ投稿確認
4. 必要なら RGBA PNG も保存し、投稿可否と見え方を比較

補足
- 出力は 3:4 固定 3072×4096
- 透明構造は単一透明色＋2値透明パターン
- プレビューは白背景/黒背景へ合成後、長辺900px相当へ縮小して近似表示
