Reveal Image Maker v0.14.0 変更内容

今回の方式: 「暗い原画」寄せのクリック後優先パターン

主な変更点
1. クリック後 / X投稿後の鮮明さを最優先にする新しい隠し画素生成方式へ変更
   - 灰色化しすぎず、元画像の色相を保ったまま暗く見せる方向へ変更
   - 特に顔・髪・輪郭・衣装の主要ディテールが読めることを優先
2. 隠し領域のパレット色数を増量
   - visible 168 / hidden 87 に再配分し、隠し領域の白黒化・粗さを抑制
3. hiddenAlphaAdaptive を停止し、挙動を固定化
   - まずはクリック後の見え方を観察しやすくするため、alpha の揺れ要因を減らしています

意図
- 白背景時: いままで通り白く隠れることを維持
- クリック後 / X投稿後: フルカラー完全再現よりも「暗い原画として読めること」を優先
- マウスオーバー: 今回は主目的ではないため、まずはクリック後の改善確認を優先
