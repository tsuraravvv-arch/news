Reveal Image Maker 更新メモ（v0.7.0 click visibility priority）

今回の調整
- クリック前の白さを維持しつつ、クリック後に隠し絵が見えやすくなる方向へ再調整
- 隠し領域のアルファを引き上げ、その代わりRGBをより白寄りへ寄せて白背景での差を抑制
- 顔・髪・衣装のディテールが残るよう、色味保持とコントラスト保持を少し強化
- 黒背景プレビューの半透明係数も少し上げ、ツール上でクリック後の見え方を確認しやすく更新
- 右上のバージョン表示は継続し、更新日時を v0.7.0 に更新

主な変更値
- hiddenAlpha: base 124 / strong 148
- toneMin: 242 -> 238（boostでやや低下）
- toneMax: 251 -> 248（boostでやや低下）
- contrast: 12 -> 18
- hueKeep: 0.12 -> 0.18
- revealHiddenAlphaScale: 1.16

意図
- 白背景では、隠した部分は現在と同等か少し強めに白く見える
- 黒背景では、半透明の白寄りRGBがより明るく残るため、顔や輪郭の視認性が上がる
- boost を上げたときは、白さを大きく崩さずにクリック後の見え方だけを少し強める
