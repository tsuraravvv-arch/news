Admin Tool (Local Only / STEP1-3)

本番記事登録ツール

採用済みのAII制作引き継ぎ情報から、Tsurara Idea Labの正式記事（data/articles.json形式）を作成し、ローカルへ登録・GitHubへPushするための管理者向けツールです。
STEP1（記事作成）・STEP2（ローカルへ登録）・STEP3（GitHubへPush） に対応しています。STEP3のPushは origin/main へ直接反映され、GitHub Pagesにも即時反映されるため、実行前には内容確認ダイアログが表示されます。

サーバー接続を確認しています…

1. 記事のもとになる情報を入力

【制作引き継ぎ AIIxxxxx】の内容を、対応する項目に入力してください。記事の事実関係はこのテキスト項目のみを根拠に作成されます（サンプル画像は見た目の参考用で、事実情報の根拠にはしません）。
CRI（【制作引き継ぎ CRIxxxxx】形式のクリエイティブトレンド情報）を貼り付けた場合は、自動判定して下の「CRIトレンド入力」欄に振り分けます。CRIは情報収集・制作管理用のIDであり、Tsurara Idea Labの正式カテゴリではありません。

制作引き継ぎをまとめて貼り付け

AII収集チャットから出力された【制作引き継ぎ AIIxxxxx】、またはCRI収集・調整チャットから出力された【制作引き継ぎ CRIxxxxx】の全文をそのまま貼り付けて「解析して反映」を押すと、種別を自動判定して下の個別項目（AIIは本フォーム内、CRIは「CRIトレンド入力」欄）へ振り分けます。振り分け後の内容は個別項目側で確認・修正してください。

3. ローカルへ登録

      

        上記の記事内容・最終公開画像・公開プレビューをすべてご確認のうえ実行してください。実行すると data/articles.json への追記と、最終画像の images/articles/ への保存を行います。登録前に data/articles.json のバックアップを別フォルダへ作成し、JSON構文・ID重複・必須項目を検証してから書き込みます。検証に失敗した場合は何も書き込みません。
      

      

        
        
      

      

    


    

      
4. GitHubへPush 最終操作

      

        ローカルへ登録した内容を origin/main へコミット・pushします。push は即座に GitHub Pages（本番サイト）へ反映されます。実行すると、まず data/articles.json をコミット（Update articles.json）し、最終画像がある場合は続けて画像もコミットしたうえで、まとめて1回だけ push します。この記事登録に関係のない変更が作業ツリーに残っている場合は、誤push防止のため自動的に中止します。
